# 蓄音キリコと　過去ログの底

蓄音キリコが、おんJ民の住みついた よその板（おんJの植民地）の過去ログへ ひとりでもぐる、1歩1ターンのローグライクです。スマホのブラウザで遊べます。

- 遊ぶ: https://onjmin.github.io/roguelike/
- 操作: 画面の8方向の十字キーと A（攻撃・決定）/ メニュー（B。1段目が もちもの。窓の中ではキャンセル）。前作と同じく ボタンは A・B だけ。A は 正面に敵がいなければ、となりの起きている敵（1匹だけのとき）のほうを向いてなぐります（眠っている敵へは 自動で 向きません）。地図を開いてタップすると、その場所まで自動で歩きます（地図は 階の 使っている 範囲に 合わせて 大きく 描きます）。壁に向かって押すと、キリコが 少し つっかえて 向きだけ 変えます。メニューを開くと、最深階・満腹度・武器と板の強さ・ちから・経験値 がメニューの窓に出ます。もちものの一覧では 同じ種類の道具が 並んで出ます。「整理」で分類の順に並べなおせます（時間は進みません）。足元の道具は、拾わずに そのまま 飲む・読む・食べる・振る・投げる・せつめい ができます（1ターン。杖や 矢の残りは 床に もどる。装備は 拾ってから）。画面に入りきらない一覧はページに分かれます（◀ ▶・左右キー）。小さいボタン（向き変え・足元・地図）は せっていで出せます（階段の上では「階段」ボタンだけ出ます）。矢は「装備」でき、装備すると A の横に「矢」ボタン（のこりの本数つき）が出て、向いている方へ1本ずつ撃てます。十字キーのまん中を長押しすると足踏み（押さえているあいだ続け、新しい敵が見えた・傷ついたら止まる。逃げるだけの敵（ROM専・ナツコ）が見えても止まらない）。行きたい場所をタップしても歩けます（通路の先や となりの通路をタップすると通路にそって走り（敵が見えていれば1歩）、画面を押さえつづけるとその方へ歩きつづけます）。
- PC: 矢印キー（2つ同時押しで斜め）・テンキー・vi キー（hjklyubn）で移動、Z/Enter で A、X で B（メニュー）、Esc もメニュー。Shift＋方向でダッシュ、R で斜め固定、F で向き変え、. で足踏み、G で足元、V で階段、M で地図、T で投げる、Q で装備した矢を撃つ、P で蓄音機を再生する、I でもちもの。
- ゲームパッド: 十字キー・左スティックで移動、A で攻撃・決定、B でメニュー（B＋方向でダッシュ、B＋A で足踏み）、Y＋方向で向き変え、LB で斜め固定、X で足元、RB で矢、START でメニュー、BACK で地図。
- 地上（保守村）: まだ 1度も もぐっていないあいだは、村の 出口を 黄色い 矢印が さします（画面の 外なら キリコの そばで 出口の 向きを さす）。十字キーかタップで歩き、A で人に話しかける・物をしらべる。立て札や 岩・蓄音機などの 1マスの 物に まっすぐ つっかえると、回りこめる 側へ 横に 1歩 ずれます（両側とも あいていれば 先へ 長く 進める 側、同じなら 村の 出口の 側。人の 前では ずれません）。開いた 植民地が 1つだけのうちは、全体マップで 選んだら すぐ 出発します。メニュー（B）で村のメニュー（持ち物・せってい）。
- 右上の 🔊 で BGM・効果音をまとめてミュートできます。
- 村の会話の読み上げ（ボイス。いまはロゼ・シヨ）は既定で OFF です。メニューの「せってい」→「ボイス」で ON にできます（初回に約45MBのデータを取得します）。ダンジョンの中のログは読み上げません。

## 物語

物語の 正本は [STORY.md](./STORY.md)（3作の 設計書）。人の 散った おんJ（保守村）で、植民地の 底から 落ちた ネタを 拾って 貼り、村を 育て直す 話です。持ち帰った ネタを 貼ると（＝売ると）スレが 伸びて、人が 来る（＝町が 育つ）。主人公の キリコは 口数が 少なく、語りでは 心の 中の 独白だけ （　）で 出し、村の 住人との 雑談と 喫茶でだけ 短く しゃべります（吾輩・ンゴ）。持ち帰った 板の 過去ログからは、去った 人の 最後の 書きこみが「古い スレの 切れはし」として 村の まとめ掲示板に 1回の 帰りに 1枚ずつ 貼られます（`src/data/scraps.ts`）。

## どんなゲームか

毎回レベル1から、植民地のいちばん底の品を拾って、地上の村まで持ち帰れたらクリアです。倒れたら持ち物はすべてなくなり、残るのは「何階で何にやられたか」という記録と、遊んだ人の知識だけです。

道具の種類はむやみに増やさず、限られた道具をやりくりして判断を重ねる遊びにしています。そのうえで、このゲームにしかない仕組みを3つ入れています。

### 1つの階は 1本のスレ（レス数）

- 1ターンで 1レス伸びます。起きた祭り（モンスターハウス）の部屋に野次馬が残っているあいだは、勢いでもう1レス伸びます。
- 950 で床が揺れ、980 で埋めが始まり、1000 で dat落ちして下の階へ落とされます。
- 画面の満腹度の横に「123レス」と出ます（950 から赤）。

### 安価

- 2階から、階に「安価の罠」が1〜2個隠れています。踏むと「安価が　来た：草を　1つ　飲む」と来ます（前のレスが今のレス番を安価で取っている形）。パン板の2階だけは、罠のかわりに 着いたとたん かならず来ます（はじめての冒険で 安価を1度は見せる。お題は 草・スレ・パン・投げる・置く・足踏み の やさしい ものだけ）。
  - 罠は1回動くと消えます（同じ罠で何度も安価を呼べません）。見つけてよければ来ません。
  - 釣りスレでふえる罠も、1/10 で安価の罠になります。安価が出ているあいだは、踏んでも動かず残ります。
  - 帰り道・ボスの待つ階には置かれません。
- お題は、草を1つ飲む・スレを1つ読む・何か投げる・パンを1つ食う（草は「飲む」なので数えない）・敵を2体たおす・寝る・攻撃を3回受ける・杖を1回ふる・道具を1つ置く・装備をかえる・罠を1つ踏む・レベルを1つ上げる・その場で10回足踏み のどれかです。そのときの持ち物や階でできるものから選ばれます。
  - 寝る：寝落ち草・眠りの罠・眠りの呪文のどれで眠っても数えます。来るのは、正体のわかった寝落ち草を持っていて、起きる指輪をはめていないときだけです。
  - 攻撃を3回受ける：敵のなぐり・矢・息が当たった回数です（はずれや罠は数えません）。階に敵がいるときだけ来ます。
  - 杖を1回ふる：回数が0で何も起きなくても数えます。杖を持っているときだけ来ます。
  - 道具を1つ置く：足元に置いたときだけです（投げる・入れかえるは数えません）。
  - 装備をかえる：武器・板・指輪をべつの物に付けかえたときです（外すだけ・矢は数えません）。付けかえられる物があって、その枠がのろわれていないときだけ来ます。
  - 罠を1つ踏む：罠が動かなくても数えます（安価の罠は数えません）。見つかっている罠が階にあって、罠よけの指輪をはめていないときだけ来ます（落とし穴なら落ちた先に道具が置かれます）。
  - レベルを1つ上げる：つぎのレベルまで半分を切っているときだけ来ます。
  - その場で10回足踏み：足踏みのコマンドだけ数えます（眠っているあいだのターンは数えません）。
  - 寝る・攻撃を受ける・杖・置く・装備・罠・レベル・足踏みは、草・スレ・敵をたおすより来にくくしてあります。
- 100レス以内にこなせば神安価で、スレ民がその板の道具を2つ（正体つき）足元に置いていきます。
- 守らないとスレが荒れて、レスが100伸び、眠っていた敵が起き、荒らしが3体湧きます（`src/core/anka.ts`）。

### 蓄音機

- キリコは、たおした敵の声を1つだけ録ります（記録に「声を　録った」と出るのは 蓄音機が 空のときだけ。いま入っている声は メニューの「蓄音機」に出ます）。
- メニューの「蓄音機」（PC は P）で再生すると、見えている同じ種類の敵が、自分の声を聞かされて5ターン固まります。
- 声は1回で消えます。祭りや群れで効く、キリコだけの手です。

- 板は 建物に合わせて **下り**（パン屋の地下の窯・地下の菌床・銭湯の地下の源泉）と **上り**（送電鉄塔・島の岩山・大阪の雑居ビル・祭りのやぐら）があります。上りの板は 階を「3階」（HUD は 3F）と数え、いちばん上で品を拾ったら 降りて帰ります。
- 地図の置き場と道は `src/data/worldMap.ts`、描くのは `src/ui/worldMap.ts` です。
- **過去ログの底（物語の結末）**：電池板を持ち帰ると、保守村の下の古井戸に「過去ログの底」（99階）が開きます。入口は 村の広場の井戸だけで、全体マップには出ません（井戸を調べて 降りる）。植民地とちがい、深さの層ごとに景色と曲が変わります（14層。`src/data/story.ts` の `HIDDEN_ZONES`）。いちばん底の「蓄音キリコのうた」（1作目で完走してしまわれたスレ）は、この板だけ 持ったまま帰還スレで持ち帰れます。

### 地上の町（保守村）と倉庫

地上は キリコが歩ける1枚の村です。起動すると 村の上にタイトル（回る原盤と、底へ沈んでいく過去ログ。はじめる／つづきから）が出ます。中断したあとも ここに もどります。

- 北の崖の3つの穴が ダンジョンの入口。ふむと もぐるか聞かれます。まだ開いていない入口は やきうが 前に立っているか 板でふさがれていて、立て札に 開き方があります。
- 中断した冒険は、タイトルか 入口で「つづきから」（入口では「すてて はじめから」も選べる）。
- はじめの 保守村には やきう（と ぷゆゆ）しか いません。仲間は 町が 育つと 建物と いっしょに 越してきます：屋台（段1）で ロゼと ゼロ、屋根つき屋台（段2）で フェリスと シヨ（物置の 番）（`src/data/story.ts` の `FRIEND_FROM`）。来る 前の 仲間は 帰ってきた 語り・知らせ・倒れた ときにも 出てきません（ロゼが 来る 前は やきうが ネタを 貼り、売り上げは 地の文）。
- 役目は人に：解音ゼロ（と まとめ掲示板）＝冒険の記録と売り上げ、フェリス＝図鑑・あそびかた、革命シヨ＝倉庫、ロゼ＝持ち帰った道具を売る。話しかければ開けるものは、村のメニュー（B）には出しません。
- 広場の下には はじめから ぷゆゆ（レスの文末の 🥺 が歩きだした子）がいて、町が育つと おんJマイナーズが 1人ずつ（板の看板の ムッジェ・二軍の 朝コンロと ジェイトルマン・2025年生まれで 紙袋の 服を 着た エルフの ミャウミャウ も）、大きな店のころには 春音リノ（おんJ生まれの UTAU。軍服に コッペパン、一人称は DIO。音源があるので ボイスONで しゃべる）と 響化アル（おーぷん有志の UTAU。科学部の18歳で キリコの後輩。同じく しゃべる）も 越してきます。倉庫が建つころには、フェリスの相方で 避難Jを研究している ヒナリー（白衣の研究者。わかりきったことを 発表しては きちんと締める）が フェリスのとなりに 越してきます。帰るたびに 1人1つ 新しい話をします（頭の上の「！」。前の冒険や 端末の曜日・季節で変わる話もある）。どれも寄り道で、何もくれません（`src/data/mobs.ts`）。
- 倒れたり 持ち帰ったりすると、冒険の記録の札のあとで 村へ もどります。持ち帰り・帰還スレなら 仲間が入口で迎え、開いたダンジョンの知らせ・倉庫・売り上げ・町の育ちも 村の中で 仲間が話します。

持ち帰った道具で 地上の町が育ちます（`src/core/town.ts`・`src/data/town.ts`。村の地図は `src/data/village/`）。

- **帰還スレ**：風呂板 で 1回の冒険に 3枚くらい 出る。読むと「地上へ もどりますか？」と聞かれ（うっかり終えないように。聞かれた時点で正体はわかる）、もどると 持ち物を持って帰れる。持ち帰る品を持っている帰り道では効かない。
- 帰ってきたら、シヨに 倉庫へ あずける道具を渡し、残りは ロゼの店で売れて 町の売上（円）になる。町は 1回の帰りで1段まで育つ（空き地 → 屋台 → … → 大きな店の8段）。段の あいだは 小段で 刻み（全20段。1段ごとの 売上は 前の 約1.1倍、はじめは 3000円。`src/core/town.ts` の `TOWN_STEPS`）、小段ごとに おんJマイナーズが 1人ずつ 越してくる（小段は 1回の帰りで 何段でも まとめて 上がる）。つぎに だれが いつ 来るかは 出さない（ゼロの「売り上げ」の グラフは 建物の 段まで）。1回の冒険の 売り上げの 目安は `node scripts/sales-sim.mjs`。パン板 を持ち帰ると屋台、電池板 を持ち帰ると いちばん上の段になる。
- 段2 で倉庫が開く（はじめは 小屋ていどの 物置に 3つ。段4 で 板張りの 倉庫、段6 で 石造り、段7 で 銀行の 貸金庫に なり、あずけられる 数も 5・10・20・40・60と 広がる）。持ち帰った物を ぜんぶ 売れば 倉庫が 広がる 帰りは、先に 町が 育って から あずける 物を きく。村で 倉庫から 引き取った 道具（段で 1〜4個。村のメニュー「持ち物」で 見て もどせる）は、そのまま 出口から 出れば 持ちこめる。電池板・離島板・過去ログの底へは 持ちこめず、シヨが 追いかけてきて 倉庫へ もどす（全体マップの 札に「持ちこみ」が 出る）。倒れたら 持ちこんだ道具も なくなる。
- 持ちこみはリプレイにも入る（同じに始められる）。

### 道具の出かた

1回の冒険で出る道具は、**階ごとに 重みの表から 引きます**（1階に 風呂板なら 5〜7個、祭りの階は もっと多い）。

- 何が出るかは 冒険ごとに ちがいます。強い品が 2本出る回も、1本も出ない回もあります。
- 表の重みは 植民地ごとの 1回の冒険で 出る数の目安です（パン板 約72・風呂板 約165・電池板 約210）。
- 道具の種類は むやみに 増やしません。未識別の道具は、その植民地で 出る 同じ分類の種類の どれかです（せつめいの窓に 候補が 出ます）。
- モンスターの落とし物も、その階に置かれた道具の一部です。後から湧いた敵は何も持っていません。

### 帰り道

いちばん底で持ち帰る品を拾うと、階段が上り向きに変わります。帰りの階には道具が1つも落ちていませんが、満腹度も減らなくなります。行きで集めた道具だけで地上を目指す、詰めの局面です。

### 敵ごとの特徴

38体すべてに、対策を考える余地のある特徴があります（盗んでワープ・分裂・投げた草でしかとどめをさせない・なぐると吹きとばす など）。会ったことのある敵は、村（フェリス）とダンジョンのメニューの「図鑑」で特徴・出る階・強さを見られます。図鑑は冒険をまたいで残ります（持ちこせるのは知識だけ）。`pnpm test` で、全38体の特徴と対策が効くかを確かめます。

### 敵の追いかけ

見失っても 追ってきます。見失っても、最後に見た所まで来て、そのまま通路をたどってきます（まっすぐ、行き止まりでは左へ。引き返さない）。部屋に入ったら、入ってきた所とは別の出口から抜けていきます。となりにいる敵には居場所が知られます。投げつけられた敵は、投げた所へ向かってきます。

撒くには：分かれ道で2マス以上はなれて、敵が曲がらない方へ行く／敵が部屋に着く前に別の出口から出る／足の速さの差（草・杖）／階段・ワープ／眠らせる（眠ると追いかけを忘れる）／通路で前の敵をつかえさせる（後ろの敵は5ターンほどであきらめる）。

### リプレイ

終わった冒険は、村のまとめ掲示板・ゼロから選んで見返せます（新しい20回ぶん）。見終わると 村の同じ場所に もどります。再生・一時停止・速さ（1〜8倍）・次の階へ とばす、ができます。

「リプレイを わたす」で 人に 見せられます。リプレイを JSON にして deflate で縮め、base64url にしたもの（共有コード）を URL の `#r=` のあとに入れたリンクを作ります（`src/engine/share.ts`。サーバーは使わず、`#` 以降はページを配る側にも送られません）。序盤で倒れた冒険なら 1〜2KB、クリアまでで 数KB〜十数KB ほど。リンクを開くと 村の前に「もらった リプレイ」を見るか聞きます。長くて貼れないときは、コピーのかわりに テキストファイルに保存して渡し、「冒険の記録」の「読み込む」で 貼りつけるか ファイルを選んで見られます。昔の版は置いていないので、別の版で遊んだリプレイは 見る前に知らせ、ずれたところで止まります。

ゲームの中身（`src/core`）は乱数も含めて決まった動きしかしないので、「シード＋入れたコマンドの列」だけを残し、見返すときに同じ順に入れなおしています（`src/core/replay.ts`。1コマンド3文字ほどで、1回の冒険で数KB〜十数KB）。64コマンドごとに状態の指紋をはさんであり、あとの版でゲームの中身が変わって同じにならなくなったら、そこで「今の版では見られない」と出して止まります。`pnpm test` では、ボットに遊ばせた冒険（途中で何度も中断・再開をはさむ）を入れなおして、終わりの状態が1文字もちがわないことを確かめています。


## 道具の名前（2ch のことば）

道具は どれも 底に沈んだ 2ch のものです。
- 武器：ぬるぽ棒 → 名無しの剣 → ガッのバット → ワイ断ちの剣（ワイ バーンに2倍）→ コテハンの剣 → 降臨の剣 → ネ申マイク
- 盾は「板」：ダイエット板 → 雑談板 → スルー板 → 永久保存板 → 鉄板 → 火消し板 → ネ申板
- 指輪は「トリップ」：◆筋肉・◆腹いっぱい・◆大食い・◆釣られない・◆徹夜・◆スルースキル・◆sage進行・◆全力age・◆保守
- 草（w）：草・大草原・荒らし草・プロテイン草・ksk草・アク禁草・左遷草・安価草・お花畑草・寝落ち草・水分補給草・燃料投下草・晒し草。メタルぷゆゆが落とす 忍法帖の実（レベル＋1）だけは、はじめから正体がわかる専用の見た目
- スレ：おんJ の実在するスレの種類で、有識者スレ（識別）・腹筋スレ（武器＋1）・耐久スレ（板＋1）・お祓いスレ・延命スレ（錆びない）・聖地巡礼スレ（地図）・ヲチスレ（敵の位置）・発掘スレ（道具の位置）・凍結スレ・炎上スレ・避難所スレ・次スレ（杖の回数）・飯テロスレ・釣りスレ・帰還スレ
- 杖：フルボッコ・安価・寝落ち・規制・改変・隔離・ラグ・諸刃・重複・ksk
- 矢：煽りの矢・正論の矢／メシ：片親パン・ぷゆゆパン・チギュリパン
- 未識別のときは【悲報】スレ・あかい草・モナーの杖・◆orz のような呼び名になります（草は 色で そろえています）
## 装備の見た目（透過素材の差し替え）

武器・盾を装備すると、キリコの歩行グラに装備の透過素材を重ねて描きます（`public/sprites/equip/<種類>.png`。種類の名前は `src/core/data/items.ts` の id）。上から貼るだけにならないよう、素材は向き（4方向）と足踏みのコマ（2つ）ごとに描き分けてあり、腕のふりに合わせて手の位置が動きます。攻撃のときは3つの形で振ります。

1枚は 200×320 で、40×40 のセルが 5列×8行 並んでいます。

| | 列1 | 列2 | 列3 | 列4 | 列5 |
|---|---|---|---|---|---|
| 行1〜4（体の前に重ねる） | 足踏み1 | 足踏み2 | 振りかぶる | ななめ | 前 |
| 行5〜8（体のうしろ） | 同じ | | | | |

- 行は上から 上・右・下・左向き（RPGEN の歩行グラと同じ順）。前の4行とうしろの4行で1組です。
- 各セルの 左から12・上から16 の所が、キリコの 16×16 のマスの左上です。刃の先や振りは、マスの外へはみ出して描けます。
- 描く順は「うしろの行 → キリコ → 前の行」。正面は両手とも前、うしろ向きは両手とも体の向こう、横向きは手前の手が前・奥の手がうしろ、になるように描き分けます。
- 盾は振らないので、列3〜5は使いません（足踏みの列のまま）。

いま入っている素材は、`src/ui/equipArt.ts` の下描き（ドットの描き方の決まり）から `pnpm equip` で書き出したものです。描き直した PNG を同じ名前で置けば、そのまま使われます。`pnpm equip` は全部を書き出し直すので、描き直した種類があるときは `pnpm equip steel,bronze` のように、書き出す種類だけを指定してください。`pnpm dev` で `/dev/equip.html?w=steel&s=bronze` を開くと、4方向×（足踏み2コマ＋振る3つの形）を拡大して確かめられます。

## 開発

```bash
pnpm install
pnpm dev
```

- `pnpm build` … 型チェックして `build/` に出力（`GITHUB_PAGES=true` で `/roguelike/` 配下向け）
- `pnpm lint` … Biome
- `pnpm test` … 敵の特徴と対策のテスト（`src/sim/monsterTests.ts`）
- `pnpm chase` … 敵の追いかけの強さを測る（通路・部屋の出口・列になった敵などの場面で、どれだけ撒けるか。`-- --json out.json` で結果を保存して比べられる）
- `pnpm sim` … 自動プレイ（ボットに何度も潜らせて、落ちないか・どこで倒れるか・飢えないかを数える）。`-- --n 1000` で回数、`-- --seed abc` で1回だけログつき
- `pnpm loudness` … 効果音の大きさを測り直す（rpg と同じしくみ）
- `pnpm equip` … 装備の透過素材の下描きを書き出す（上の「装備の見た目」）
- `ART_TODO.md` … 作者が あとで 描く 立ち絵・歩行グラの 一覧（いまは 仮の 絵か ダミー）
- 開発中は `?seed=abc&depth=12&lv=10` で好きな階から始められます（村を とばして すぐ始まる。公開版でも `?debug` を付けると使える。この始め方は中断セーブにも記録にも残りません）。`?stage=N` で 村の段（0〜7）の見た目だけを 下見できます（保存は 書きかえない）
- main に push すると GitHub Actions が GitHub Pages に公開します

### 構成

- `src/core/` … ゲームの中身（DOM に触らない。Node の自動プレイでも動く）
  - `run.ts` 1回の冒険（ターンの進み・プレイヤーの行動・戦闘）、`floor.ts` 階の生成、`monster.ts` 敵の動き、`effects.ts` 道具の効果、`traps.ts` 罠、`itemTable.ts` 道具の出かた、`mapgen.ts` 部屋と通路、`fov.ts` 見える範囲
  - `balance.ts` 数値、`anka.ts` 安価、`data/items.ts` 道具と出かたの表、`data/monsters.ts` モンスター
  - 乱数はシードつき（`rng.ts`）で、状態ごと中断セーブに入るので、読み直しても結果は変わりません
- `src/engine/` … 画面・入力・音・素材・設定（rpg「蓄音キリコの大冒険」から流用。スマホのバー対策・ダブルタップ拡大対策もそのまま）
- `src/ui/` … 描画・HUD・メニュー・記録・歩ける村（`village.ts`・`villageEvents.ts`・`villageReturn.ts`・`villageTalk.ts`）・起動のタイトル（`boot.ts`）
- `src/sim/bot.ts`・`scripts/sim.mjs` … 自動プレイ
