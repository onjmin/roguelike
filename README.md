# 蓄音キリコと　過去ログの底

蓄音キリコが、dat落ちしたスレが積もる「過去ログの底」へひとりでもぐる、トルネコの大冒険（1作目）風のローグライクです。スマホのブラウザで遊べます。

- 遊ぶ: https://onjmin.github.io/roguelike/
- 操作: 画面の8方向の十字キーと A（攻撃・決定）/ B（メニュー・キャンセル）。小さいボタンは 向き変え・足元・地図の3つだけ。十字キーのまん中を長押しすると足踏み（押さえているあいだ続け、敵が見えた・傷ついたら止まる）。行きたい場所をタップしても歩けます（通路の先をタップすると通路にそって走り、画面を押さえつづけるとその方へ歩きつづけます）。
- PC: 矢印キー（2つ同時押しで斜め）・テンキー・vi キー（hjklyubn）で移動、Z/Enter で A、X/Esc で B。Shift＋方向でダッシュ、R で斜め固定、F で向き変え、. で足踏み、G で足元、M で地図、T で投げる。
- 右上の 🔊 で BGM・効果音をまとめてミュートできます。

## どんなゲームか

1歩1ターン。毎回レベル1から、いちばん底の品を拾って、地上まで持ち帰れたらクリアです。

ダンジョンはトルネコ1（ちょっと不思議 → 不思議 → もっと不思議）にならって3つあり、順に開きます。

| ダンジョン | 階 | 持ち帰る品 | きまり | 開く |
|---|---|---|---|---|
| ちょっと過去ログの底 | 10 | 蓄音機の針 | 杖だけ未識別・のろいなし・祭りなし・罠は B5 から。始めに 大きなパン・薬草・鑑定スレ | はじめから |
| 過去ログの底 | 20 | はじまりの原盤 | 草・スレ・指輪・杖が未識別 | ちょっと を持ち帰る（10回倒れても開く） |
| もっと過去ログの底 | 30 | つづきの原盤 | 大きなパン・不食の指輪が出ない・罠が多い・祭りが出やすい | 過去ログの底 を持ち帰る |

それぞれ、はじめて入る前に短い語りがあり、持ち帰ると仲間が迎えます（地上で待つ仲間が、タイトルでキリコのうしろを歩くようになります）。語りは `src/data/story.ts`、ダンジョンの中身は `src/core/data/dungeons.ts`。倒れたら持ち物はすべてなくなり、残るのは「何階で何にやられたか」という記録と、遊んだ人の知識だけです。

トルネコ1が面白いのは、**限られた持ち札をやりくりする**遊びだからだ、という考えで作っています。将棋やトランプのように、使える資源の全体が決まっていて、その中で判断を重ねる。2作目以降やポケダンで増えた「資源を広げる仕組み」は入れていません。

| 入れたもの（トルネコ1と同じ） | 入れなかったもの |
|---|---|
| 満腹度（10ターンで1%）、自然回復、レベルは毎回1から | 壺・合成・職業・技・仲間 |
| 未識別（草・スレ・杖・指輪）、のろい、罠、持ち物は20枠 | ダンジョンの店・ゴールド |
| 攻撃力・経験値・ダメージの式、命中7/8、64ターンごとの湧き、長居すると地震 | 持ち込み・倉庫・周回での強化 |
| モンスターハウス（ここでは「祭り」。B6 までに必ず1度。浅い階のは小さめ）、帰り道は補給なし | 救助・風で地上へ |

### 地上の町（保守村）と倉庫

トルネコ1の「店が大きくなる」にならって、持ち帰った道具で 地上の町が育ちます（`src/core/town.ts`・`src/data/town.ts`）。

- **帰還スレ**（リレミトにあたる）：過去ログの底 の山札に3枚。読むと「地上へ もどりますか？」と聞かれ（うっかり終えないように。聞かれた時点で正体はわかる）、もどると 持ち物を持って帰れる。持ち帰る品を持っている帰り道では効かない。
- 帰ってきたら、倉庫に あずける道具を選び、残りは ロゼの店で売れて 町の売上（レス）になる。町は 1回の帰りで1段まで育つ（空き地 → 屋台 → … → 大きな店の8段）。ちょっと を持ち帰ると屋台、過去ログの底 を持ち帰ると いちばん上の段になる。
- 段4 で倉庫が開き、倉庫の道具を **過去ログの底にだけ** 1〜4個 持ちこめる（ちょっと・もっと には持ちこめない。もっと は「決まった札だけで やりくり」のまま）。倒れたら 持ちこんだ道具も なくなる。
- 持ちこみはリプレイにも入る（同じに始められる）。

### 山札（この作品の軸）

1回の冒険で出る道具は、**中身の決まった山札**から配られます（ちょっと 70枚・過去ログの底 144枚・もっと 210枚）。

- 中身（何が何枚）は毎回同じで公開されています。冒険ごとに変わるのは並びだけです。メニューの「山札」で、各道具が全部で何枚あって、そのうち何枚を見たかがわかります。
- 山札は上・中・下の3層に種類が均等になるよう分けてから切るので、同じ種類が浅い階に偏りにくくなっています。
- **札は増えません**。モンスターの落とし物も、その階に配られた札の一部です。後から湧いた敵は何も持っていません。
- 拾わずに階段を降りた札は「流れ」、地雷や炎で燃えた札は「なくなり」ます。
- 画面上の「のこり札」は、この階でまだ見ていない札の枚数です。探索を続けるか降りるかを決めるときの目安になります。
- **数えて識別できます**。未識別の名前ごとに見た枚数が出るので、「【悲報】スレを4枚見た。全部で2枚しかない種類ではない」のように、消去法で正体をしぼれます（トルネコの値段識別の代わりです）。
- パンも山札に入っているので、冒険全体で使えるターン数の上限も決まっています。

### 帰り道

地下20階で原盤を拾うと、階段が上り向きに変わります。帰りの階には札が1枚も配られません（山札は尽きています）が、満腹度も減らなくなります。手札だけで地上を目指す、詰めの局面です。

### 層（深くなるほど変わるもの）

20階は6つの層に分かれていて、層が変わると地形の見た目・曲・空気中をただよう粒が変わります。出てくる敵は1体ずつ出る階が決まっているので、階ごとに顔ぶれが入れ替わります。

| 階 | 層 | 地形 | 曲 | 粒 |
|---|---|---|---|---|
| B1〜4 | 過去ログの浅瀬 | 土 | dungeon | ほこり |
| B5〜8 | 苔むしたスレ跡 | 苔 | field | 胞子 |
| B9〜12 | 凍結された書庫 | 水晶 | field2 | 雪 |
| B13〜16 | 鯖の深部 | 電脳 | tense | データのかけら |
| B17〜19 | 炎上の底 | 溶岩 | boss | 火の粉 |
| B20 | はじまりの原盤 | 金 | lastboss | きらめき |

帰り道の曲は title です。表は `src/ui/theme.ts` の `ZONES` にあります。

### 敵ごとの特徴

31体すべてに、トルネコ1のように対策を考える余地のある特徴があります（盗んでワープ・分裂・投げた薬草でしかとどめをさせない・なぐると吹きとばす など）。会ったことのある敵は、タイトルとメニューの「図鑑」で特徴・出る階・強さを見られます。図鑑は冒険をまたいで残ります（持ちこせるのは知識だけ）。`pnpm test` で、全31体の特徴と対策が効くかを確かめます。

### 敵の追いかけ

トルネコ1（と SFC シレン）と同じ考え方で追ってきます。見失っても、最後に見た所まで来て、そのまま通路をたどってきます（まっすぐ、行き止まりでは左へ。引き返さない）。部屋に入ったら、入ってきた所とは別の出口から抜けていきます。となりにいる敵には居場所が知られます。投げつけられた敵は、投げた所へ向かってきます。

撒くには：分かれ道で2マス以上はなれて、敵が曲がらない方へ行く／敵が部屋に着く前に別の出口から出る／足の速さの差（草・杖）／階段・ワープ／眠らせる（眠ると追いかけを忘れる）／通路で前の敵をつかえさせる（後ろの敵は5ターンほどであきらめる）。

### リプレイ

終わった冒険は、タイトルの「冒険の記録」から選んで見返せます（新しい20回ぶん）。再生・一時停止・速さ（1〜8倍）・次の階へ とばす、ができます。

ゲームの中身（`src/core`）は乱数も含めて決まった動きしかしないので、「シード＋入れたコマンドの列」だけを残し、見返すときに同じ順に入れなおしています（`src/core/replay.ts`。1コマンド3文字ほどで、1回の冒険で数KB〜十数KB）。64コマンドごとに状態の指紋をはさんであり、あとの版でゲームの中身が変わって同じにならなくなったら、そこで「今の版では見られない」と出して止まります。`pnpm test` では、ボットに遊ばせた冒険（途中で何度も中断・再開をはさむ）を入れなおして、終わりの状態が1文字もちがわないことを確かめています。

## 装備の見た目（透過素材の差し替え）

武器・盾を装備すると、キリコの歩行グラに装備の透過素材を重ねて描きます（`public/sprites/equip/<種類>.png`。種類の名前は `src/core/data/items.ts` の id）。上から貼るだけにならないよう、素材は向き（4方向）と足踏みのコマ（2つ）ごとに描き分けてあり、腕のふりに合わせて手の位置が動きます。攻撃のときは3つの形で振ります。

1枚は 200×320 で、40×40 のセルが 5列×8行 並んでいます。

| | 列1 | 列2 | 列3 | 列4 | 列5 |
|---|---|---|---|---|---|
| 行1〜4（体の前に重ねる） | 足踏み1 | 足踏み2 | 振りかぶる | ななめ | 前 |
| 行5〜8（体のうしろ） | 同じ | | | | |

- 行は上から 上・右・下・左向き（RPGEN の歩行グラと同じ順）。前の4行とうしろの4行で1組です。
- 各セルの 左から12・上から16 の所が、キリコの 16×16 のマスの左上です。刃の先や振りは、マスの外へはみ出して描けます。
- 描く順は「うしろの行 → キリコ → 前の行」。正面は両手とも前、うしろ向きは両手とも体の向こう、横向きは手前の手が前・奥の手がうしろ、になるように描き分けます。
- 盾は振らないので、列3〜5は使いません（足踏みの列のまま）。

いま入っている素材は、`src/ui/equipArt.ts` の下描き（ドットの描き方の決まり）から `pnpm equip` で書き出したものです。描き直した PNG を同じ名前で置けば、そのまま使われます。`pnpm equip` は全部を書き出し直すので、描き直した種類があるときは `pnpm equip steel,bronze` のように、書き出す種類だけを指定してください。`pnpm dev` で `/dev/equip.html?w=steel&s=bronze` を開くと、4方向×（足踏み2コマ＋振る3つの形）を拡大して確かめられます。

## 開発

```bash
pnpm install
pnpm dev
```

- `pnpm build` … 型チェックして `build/` に出力（`GITHUB_PAGES=true` で `/roguelike/` 配下向け）
- `pnpm lint` … Biome
- `pnpm test` … 敵の特徴と対策のテスト（`src/sim/monsterTests.ts`）
- `pnpm chase` … 敵の追いかけの強さを測る（通路・部屋の出口・列になった敵などの場面で、どれだけ撒けるか。`-- --json out.json` で結果を保存して比べられる）
- `pnpm sim` … 自動プレイ（ボットに何度も潜らせて、落ちないか・どこで倒れるか・飢えないかを数える）。`-- --n 1000` で回数、`-- --seed abc` で1回だけログつき
- `pnpm loudness` … 効果音の大きさを測り直す（rpg と同じしくみ）
- `pnpm equip` … 装備の透過素材の下描きを書き出す（上の「装備の見た目」）
- 開発中は `?seed=abc&depth=12&lv=10` で好きな階から始められます（公開版でも `?debug` を付けると使える。この始め方は中断セーブにも記録にも残りません）
- main に push すると GitHub Actions が GitHub Pages に公開します

### 構成

- `src/core/` … ゲームの中身（DOM に触らない。Node の自動プレイでも動く）
  - `run.ts` 1回の冒険（ターンの進み・プレイヤーの行動・戦闘）、`floor.ts` 階の生成、`monster.ts` 敵の動き、`effects.ts` 道具の効果、`traps.ts` 罠、`deck.ts` 山札の配り方、`mapgen.ts` 部屋と通路、`fov.ts` 見える範囲
  - `balance.ts` 数値（トルネコ1の解析値に寄せている）、`data/items.ts` 道具と山札の中身、`data/monsters.ts` モンスター
  - 乱数はシードつき（`rng.ts`）で、状態ごと中断セーブに入るので、読み直しても結果は変わりません
- `src/engine/` … 画面・入力・音・素材・設定（rpg「蓄音キリコの大冒険」から流用。スマホのバー対策・ダブルタップ拡大対策もそのまま）
- `src/ui/` … 描画・HUD・メニュー・タイトル・記録
- `src/sim/bot.ts`・`scripts/sim.mjs` … 自動プレイ
